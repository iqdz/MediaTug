# MediaTug
================================================================================                           MEDIA TUG - APP DESCRIPTION ================================================================================  PROJECT NAME: Media Tug VERSION: 1.0 PLATFORM: Windows 10/11 (64-bit and 32-bit) LANGUAGE: Python 3.9+ LICENSE: GNU General Public License v2 (GPL-2.0) AUTHOR: Harith  ================================================================================ OVERVIEW ================================================================================  Media Tug is a fully accessible Windows desktop application designed to search, play, and download media from YouTube and other web sources. Built from the ground up with screen reader users (NVDA, JAWS, Narrator) as the primary audience, it provides a keyboard-driven interface with zero reliance on visual UI chrome or mouse-only controls.  The application combines yt-dlp (powerful media extraction) with libvlc (lightweight playback engine) in a wxPython GUI that prioritizes clarity, keyboard accessibility, and offline functionality. It runs on any Windows computer with Python 3.9+ or as a fully self-contained portable executable requiring no installation.  ================================================================================ KEY FEATURES ================================================================================  1. ACCESSIBLE INTERFACE    - Full keyboard navigation; no mouse required    - Screen reader optimized (NVDA, JAWS, Narrator)    - Minimal UI nesting to reduce verbosity    - Status bar for live announcements    - Explicit control naming for clarity    - Flat structure without nested dialogs  2. MEDIA SEARCH & DISCOVERY    - Search across YouTube and 1000+ supported platforms (via yt-dlp)    - Results displayed in accessible list with title, duration, URL    - Pagination: auto-loads 10 more results as you scroll to bottom    - Direct URL input: paste a video link and press Enter    - Channel/playlist detection by URL shape (no extra network call needed)  3. PLAYBACK ENGINE    - Powered by libvlc (lightweight, headless video rendering)    - Hidden video panel (audio-focused; video disabled by default)    - No embedded player UI that can steal keyboard focus    - Direct playback from local cache files (works around anti-bot 403s)    - Full transport controls: play/pause, volume, seek, mute  4. DOWNLOADS & QUALITY CONTROL    - Video: MP4 format with quality selection (Best, 1080p, 720p, 480p, 360p)    - Audio: MP3 with bitrate selection (128 kbps, 192 kbps, 320 kbps)    - Single video download with progress reporting    - Batch operations: download entire playlists or channels in one go    - Download archive tracking: resume interrupted batch downloads without      re-fetching completed videos    - Generous retries (30+) for long channel/playlist downloads  5. ANTI-BOT PROTECTION WORKAROUNDS    - Browser cookie integration (Firefox, Edge, Chrome, Brave, Vivaldi, Opera)    - Auto-detection of installed browsers; falls back gracefully    - Manual cookies.txt support (export from browser via extension)    - Client fallback list for YouTube playback challenges    - Local caching: downloads media to disk first, plays from cache      (bypasses direct stream 403 errors completely)  6. CONTEXT MENU ACTIONS    - Play Video: Open media in dedicated player window    - Download Video (MP4): Save to disk with configured quality    - Download Audio (MP3): Extract and save with configured bitrate    - Open in Web Browser: Launch default browser to media page    - Copy URL to Clipboard: Quick link sharing    - Send URL by Email: Open default email app with subject/body pre-filled  7. SETTINGS & CONFIGURATION    - Download directory: persistent choice stored in JSON config    - Format & quality: radio button for video/audio, choice dropdowns    - Playback timing: customizable skip length (1–120 seconds)    - Volume step: customizable volume increment per key (1–50%)    - Cache retention: auto-delete played media after 1, 2, 7, or 30 days    - Browser cookie source: auto-select or pick specific browser    - Custom cookies file path: browse or type path to cookies.txt    - Debug logging: toggle detailed diagnostics to file and UI log  8. PORTABLE DEPLOYMENT    - Single executable (PyInstaller onedir build)    - Optional: bundle VLC runtime for zero-dependency portability    - Folder structure: app/, cookies/, data/, logs/ (data outside app/ survives      app updates)    - Works on any Windows machine with no installer or PATH configuration    - Dev mode: run.bat installs dependencies to local libs/ folder; entire      folder can be copied with Python installed elsewhere  9. HOTKEY SUPPORT    - Frame-level accelerator table (Ctrl+letter combos pass through to text      controls safely)    - Global hotkeys: Ctrl+F (search), Alt+S (settings)    - Player window hotkeys: Space/Ctrl+P (play/pause), Ctrl+M (mute),      arrow keys (volume/seek), Escape/Ctrl+W (close)    - Results list: Arrow keys (navigate), Enter (play), Escape (close),      Down on last item (load more)  10. DIAGNOSTICS & TROUBLESHOOTING     - Activity log with scrollback (readable by tabbing in)     - Status bar for live screen-reader announcements     - Debug logging to file (media_tug_debug.log)     - VLC native log output (vlc_native.log) when enabled     - Detailed error messages for 403, network, cookie, and playback issues     - YoutubeDL bridge: captures yt-dlp's own warnings/errors  ================================================================================ TECHNICAL ARCHITECTURE ================================================================================  COMPONENTS:  1. PlayerController    - Wraps python-vlc bindings    - Manages playback state, volume, seeking, muting    - Renders into hidden win32 HWND (no UI chrome)    - Event handlers for VLC state transitions (opening, buffering, playing,      error, end-reached)    - Debug logging for each state change  2. SettingsDialog    - Modal wxPython dialog with accessible form controls    - Checkboxes, choice dropdowns, spin controls, text fields    - Browse buttons for folder and file selection    - Save/cancel buttons with immediate config persistence    - Tooltips and labels for all controls  3. PlayerWindow    - Modal dialog for dedicated playback (opens on media selection)    - Single status text control (no nested group boxes)    - EVT_CHAR_HOOK for hotkey capture before child control dispatch    - Full instructions in window title (announced once on open)    - Closes on Escape or Ctrl+W; stops playback on close  4. AccessibleDownloaderFrame    - Main application window (wx.Frame)    - Layout: title, buttons (Settings, About), search box, results list,      activity log, status bar    - Main sizer toggles results panel visibility (Escape hides it)    - Playback cache directory with age-based pruning on startup    - First-run dialog offers desktop shortcut creation  5. Search & Results    - yt-dlp's extract_flat mode for fast, metadata-only extraction    - Search query: "ytsearch10:keywords" or direct URL    - Results stored in dict with title, URL, duration    - ListCtrl displays title (450px), duration (100px), URL (180px)    - Selection tracking for context menu actions  6. Playback Flow    - User selects result → play_media() called    - resolve_and_play() runs in background thread    - yt-dlp downloads to playback_cache/ (temp storage)    - PlayerController.load() opens local file    - PlayerWindow shows and updates status as VLC state changes    - On close: cache file kept (not deleted immediately), pruned by age later  7. Cookie Resolution    - resolve_cookie_config() tries sources in order:      a) cookies.txt file (if specified in settings or dropped in cookies/ folder)      b) Browser cookies (auto-detected order: Firefox, Edge, Chrome, Brave,         Vivaldi, Opera)      c) No cookies (fallback)    - Caches working browser label (cookie_label) for future attempts    - Graceful fallback: if one browser fails, tries next  8. Download Flow    - Single video: run_download_task() in background thread    - Channel/playlist: run_channel_download_task() with archive file    - Progress hooks update UI with percent, ETA    - Finished hook logs success and fires postprocessor (audio extraction)    - Errors logged with full traceback to debug log  DEPENDENCIES:  - wxPython 4.1+ (GUI framework, accessible controls) - python-vlc 3.0+ (libvlc bindings) - yt-dlp (nightly channel recommended; YouTube protections change frequently) - curl_cffi (browser impersonation for yt-dlp) - FFmpeg (bundled by yt-dlp for audio conversion) - Deno (external; yt-dlp invokes for JavaScript solver)  ================================================================================ USE CASES ================================================================================  1. SCREEN READER USERS    - Primary audience; every UI element keyboard-navigable    - Download and watch media offline without browser accessibility issues    - Full hotkey support for player control without tabbing through UI  2. YOUTUBE CHANNEL ARCHIVING    - Download entire channel in one batch operation with resume support    - Automatic retry on transient network errors    - Tracks downloaded videos; skips on re-run  3. PODCAST & AUDIO CONSUMPTION    - Search and extract audio from YouTube, Vimeo, Spotify, SoundCloud, etc.    - Configurable bitrate; offline listening    - Fast forward/rewind hotkeys; mute shortcut  4. AGE-GATED CONTENT ACCESS    - Use browser cookies to access age-restricted videos    - Firefox recommended (no DPAPI overhead)  5. MEDIA SHARING    - Context menu "Send URL by Email" for quick sharing    - Pre-filled subject and body; opens default email client  ================================================================================ BUILD & DEPLOYMENT ================================================================================  DEVELOPMENT MODE (run.bat): - Checks Python version - Installs dependencies to local libs/ folder (--target pip flag) - Auto-upgrades yt-dlp nightly channel (YouTube changes protections often) - Installs curl_cffi and python-vlc if missing - Attempts auto-install of Deno via winget (fallback: manual install from   https://deno.com) - Launches media_tug.py directly  PORTABLE BUILD (build.bat): - Upgrades dependencies globally - PyInstaller: onedir mode, windowed, single exe inside app/ folder - Assembles Media_Tug/ folder with app/, cookies/, data/, logs/ subfolders - Copies libvlc.dll, libvlccore.dll, plugins/ from VLC install if found - Outputs folder structure ready to zip and distribute - Entire folder is self-contained; no system installation required  ================================================================================ FILE STRUCTURE ================================================================================  MediaTug_GitHub_Repo/ ├── media_tug.py           (1429 lines; KEYBOARD NAVIGATION    - Tab/Shift+Tab cycles through controls in logical order    - Arrow keys in lists (results, settings)    - Space on checkboxes and buttons    - Enter on text fields to submit (search) or activate  2. NAMING & LABELS    - All controls have explicit labels (SetName, Label in constructor)    - Static text boxes provide context (e.g., "Skip length in seconds")    - Button tooltips explain function concisely  3. SCREEN READER ANNOUNCEMENTS    - Status bar (SetStatusText) picked up as live region by NVDA/JAWS    - Activity log (scrollback) searchable by tabbing in    - Frame title includes current action (e.g., "Now Playing: [Title]")  4. FOCUS MANAGEMENT    - Explicit focus calls (SetFocus) after important actions    - First-run: focus set to search box after initialization    - Search complete: focus set to results list    - Player close: focus returned to results list  5. MINIMAL VERBOSITY    - Flat UI; no unnecessary grouping boxes    - PlayerWindow title contains full instructions (read once on open)    - Tooltips used instead of repeated help text    - Status bar used instead of modal dialogs where possible  6. HOTKEY ACCESSIBILITY    - EVT_CHAR_HOOK at frame level for global hotkeys    - Ctrl+letter combos don't interfere with text input    - Arrow keys in lists allow navigation + transport control (Escape to close)    - Player window captures all keys; no focus trapping on other controls  ================================================================================ KNOWN LIMITATIONS & WORKAROUNDS ================================================================================  1. YOUTUBE 403 ERRORS    - Cause: Server-side anti-bot signing on direct googlevideo URLs    - Workaround: Local caching (download to disk, play locally)    - Further workaround: Browser cookies + client fallback list  2. VLC DEPENDENCY    - Required for playback    - Bundled in portable build (if VLC installed on build machine)    - If missing: system VLC install or manual DLL copy to app/ folder  3. DENO REQUIREMENT    - Optional for development mode; yt-dlp may invoke for JavaScript solving    - Auto-install via winget attempted; fallback to manual install from      https://deno.com  4. YOUTUBE CHANNEL DOWNLOAD TIME    - Large channels (1000+ videos) may take hours    - resume-on-retry via download_archive.txt    - Generous retries (30+) handle transient failures  5. COOKIES & AUTHENTICATION    - Browser cookies expire; refresh periodically    - Firefox recommended (no Windows DPAPI overhead)    - Some Chromium browsers have decryption issues on certain systems  ================================================================================ FUTURE ENHANCEMENTS ================================================================================  - Additional media platforms (Twitch, Vimeo, etc.) via yt-dlp - Video transcoding presets (e.g., mobile-friendly conversion) - Playlist management (save, export, import) - Download queue visualization - Subtitle support and caption extraction - Live stream recording (where supported) - Integration with media servers (Plex, Jellyfin) - Automatic metadata tagging (ID3 for audio files) - Batch URL import from clipboard or file  ================================================================================ SUPPORT & CONTRIBUTION ================================================================================  REPORTING ISSUES: - GitHub Issues: Describe the problem, error message, and debug log output - Email: harith@gvoice.org  CONTRIBUTING CODE: - Fork the repository - Create a feature branch - Submit a pull request with a clear description  SUPPORT DEVELOPMENT: - Ko-fi: https://ko-fi.com/happs#  ================================================================================ LICENSE ================================================================================  Media Tug is released under the GNU General Public License v2 (GPL-2.0).
